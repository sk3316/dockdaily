# DockDaily

DockDaily is a simple personal productivity app for tracking everyday tasks and habits in one place. It uses a local SQLite database, so your data stays on-device and the app works as a lightweight daily planner rather than a cloud-based service.

## What the app can do

- Create and manage tasks with a title, priority, due date, notes, and completed state.
- Mark tasks complete individually or in bulk.
- Edit task names, delete tasks, and search through your task list.
- Track habits as yes/no check-ins, counted goals, or timed goals.
- Set a target for each habit and record today’s progress.
- See habit streaks based on completed daily logs.
- Remove habits when you no longer want to track them.
- View a basic stats screen for progress insights.

## How it is organized

- Tasks live in the `Tasks` tab.
- Habits live in the `Habits` tab.
- Progress summaries live in the `Stats` tab.

## Data storage

DockDaily stores its data locally with SQLite tables for tasks, habits, and habit logs. That means the app is designed for offline use and fast everyday tracking.

## Best fit

This app is a good fit for someone who wants a focused daily system for getting things done, building habits, and keeping the two together in a single mobile-friendly interface.
